# ネジキチートシート

**ライブラリ名から操作を探し、必要な全体コードをコピーするための資料です。**

## ブラウザ用HTML

**[ブラウザ用リファレンスを開く](https://neziki2149.github.io/github-test/competitive-programming-reference/)**

GitHub Pages公開後に上のURLで閲覧できます。ローカルでは [index.html](index.html) をダウンロードし、ブラウザで開いても使えます。HTMLは1ファイルで完結し、閲覧・検索・コードの展開・コピーはブラウザ内で動作します。生成AIへの問い合わせや外部スクリプトの読み込みはありません。

- **標準ライブラリ**：容器と操作関数を分け、「日本語の機能 → 短いコード → 計算量」の順に掲載。
- **アルゴリズム**：名前と機能を1項目ずつ独立させ、読みの50音順に掲載。累積和・いもす法・ダブリング・強連結成分分解なども別項目。
- **全体コード**：アルゴリズムは「名前 → 目的 → 計算量・メモリ → 展開済みコード」の順に表示。標準ライブラリ・ACLも操作ごとに選択し、短いコードと展開済みの全体コードを表示します。短いコード専用のコピーボタンも利用できます。`#include`・`main()`・必要な補助関数を含み、コピー・C++ファイルの保存に対応。
- **検索**：関数名・日本語・別名で、すべての分類から検索。`/` で検索欄に移動、`Esc` で検索解除。
- **項目の切り替え**：目次で選んだ1項目だけを本文に表示。選択中の目次はハイライトを保持し、別項目を選ぶと本文を切り替えます。検索結果も目次から1項目ずつ開きます。
- **目次**：標準ライブラリ・ACLはグループを1つずつ開閉して操作を選択。計算量の文字の意味・追加メモリ・必要な注意点を各操作に掲載。紛らわしい操作には実行前後の例を掲載。
- **計算ツール**：初期状態はコンテナ未選択。選択後に必要な入力欄と計算結果を表示します。配列は「配列（vector）」に一本化し、一次元／二次元と型を選んで容量を計算して、選択式のメモリ制限（MB）と比較。long long・doubleは別の選択肢。vector・set・multiset・map・unordered_set・unordered_mapは64 bit Linux・GCC系実装の管理領域込みの推定容量を表示。計算機の表示単位はMBに統一し、制限に対する割合は推定範囲の大きい方から計算します。結果は「使用メモリ量 : 推定容量 / 制限」と割合の2行で表示。メモリの表は各容量セルにMBを付記します。数値は実測値や絶対的な上限ではありません。計算量の規模もNを選択して確認できます。
- **表記**：添字は0始まり、区間は「l以上r未満」。数値の規模は `10²`・`2×10⁵` のように表記。

共通の前提はこのREADMEで確認できます。各項目の本文は選んだ内容から始まり、章タイトルや共通のバッジは繰り返し表示しません。和・積・距離などの計算結果は使用する型の範囲内に収め、到達できない地点を表す `INF` は、あり得る距離より大きい値を設定してください。

## スマホ用C++エディタ（試作版）

**[スマホ用エディタを開く](mobile-editor.html)** — スマートフォンの縦・横どちらの画面でも、JIS配列を元にした常設の画面キーボードでC++コードを編集し、AtCoderの提出欄へコピーして貼り付けるためのページです。コンパイル・コード実行機能はありません。

- 初期コード: `#include <bits/stdc++.h>`、`using namespace std;`、空の `main()` を用意。
- キーボード: Fキー列、右Shift、CapsLock、Altを除外。Tab・Enter・左Ctrlを拡大し、削除（⌫）・十字キーを常設。Shift・Ctrlはタップで有効化。縦画面ではキーを押しやすくするため、標準で左右スクロール式のキーボードに切り替わります。左右ボタンでも移動でき、`全体表示` を押すと縮小して全キーを一度に表示します。横画面は従来どおり。
- コピー／貼り付け: 右上のボタン。Ctrl→A→貼り付けでコード全体を置換。選択中は選択範囲を置換し、それ以外はカーソル位置へ挿入。
- ショートカット: Ctrl+A/C/X/V/Z/Y。Shift＋十字キーで範囲選択。矢印・削除は長押しで連続操作。
- 保存: 同じブラウザ・端末内の `localStorage` に自動保存。新規ボタンで初期テンプレートに戻せます。端末やブラウザを変えた場合は同期されません。

**注意:** Safariではクリップボード読み取り時に「貼り付け」の確認が表示される場合があります。iPhone実機での縦・横画面表示、カーソル選択、端末固有の操作は継続検証が必要な試作版です。OSキーボードを避けるため編集領域を読み取り専用にし、独自キーボードの操作でコードを変更しています。

## コードの使用

使用言語は **C++23 (GCC 15.2.0)**、ローカルのコンパイル設定は **`-std=gnu++23`** を前提とします。[AtCoder公式の言語・コンパイル設定](https://img.atcoder.jp/file/language-update/2025-10/language-list.html)

`bits/stdc++.h` はGCC系環境向けです。**ACLの例にはAtCoder Libraryのヘッダが別途必要です。** [コンパイル方法](examples/README.md) / [ACL公式ドキュメント](https://atcoder.github.io/ac-library/production/document_ja/index.html)

この資料のコードは生成AIを用いて事前作成しています。ABC・ARC・AGCでコピーして使用する場合、コンテスト開始前のWeb公開と、提出コードへの参照URLの添付が必要です。HTMLの全体コードには出典コメントを含めています。公開コミットの時刻が参加するコンテストの開始前であることを確認してください。[AtCoder公式ルール](https://info.atcoder.jp/entry/llm-rules-ja)

参照内容を固定する場合は、GitHubで対象ファイルを開き `y` キーでコミット固定URLを取得できます。

## 更新と検証

内容は `build_reference.py`、画面は `page-template.html` で管理します。生成物を直接変更するのではなく、次のコマンドでHTML・Markdown・検証データをまとめて生成します。

```sh
python build_reference.py
```

サイト内の**更新履歴・制作者メモ**は、公開する記録を `site-notes.json`、下書きをローカル専用の `site-notes.local.json` に記録します。`published: true` の項目だけがサイトと生成Markdownに表示されます。`site-notes.local.json` は公開リポジトリにアップロードしないでください。DSU・Fenwick Tree・segtreeの表示を戻す場合は、`build_reference.py` の `HIDDEN_GROUPS` からキーを削除します。

全コードの検証（WSL/Linux、Python3・g++・インターネット接続が必要）：

```sh
python3 validate.py
```

検証スクリプトは公式ACLを一時フォルダへ取得します。サイトに掲載中の全体コードを、それぞれの本文を別の名前空間に置いてC++23 (GCC 15.2.0)で一括コンパイルし、実行可能な例を動かします。単独cppファイル7本のコンパイルと、境界値・ランダム入力の出力照合も行います。すべての入力や手法を網羅する検証ではありません。

GitHub Pagesの初回設定は、[Settings → Pages](https://github.com/NEZIKI2149/github-test/settings/pages)で **Deploy from a branch → master → /(root) → Save**。リポジトリ直下の入口から、この資料へ移動する構成です。
